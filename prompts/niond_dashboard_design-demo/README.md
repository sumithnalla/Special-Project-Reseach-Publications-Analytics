# Niond Sales Dashboard

A responsive, front-end dashboard inspired by the supplied reference image.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.

No Node.js, database, or installation is required.

## Included interactions
- Sidebar navigation with active state and section dialogs
- Mobile navigation drawer
- Notifications and help dialogs
- Team member detail dialogs
- Add a team member (stored in the current page session)
- Export the Top Store table as CSV
- Share/copy the Top Store summary
- Upgrade and meeting information dialogs

## Important
This is a front-end demo with sample data. Login, payment processing, live meeting links, persistent team records, and database-backed analytics are not connected. Those require a backend/API and credentials.
